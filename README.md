My First HTML Project – The Odin Project
📌 About the Project

This is my first HTML project, completed as part of The Odin Project Foundations course.

The main goal of this project was to put my newly acquired HTML knowledge into practice by building a structured website from scratch. Throughout the project, I applied the fundamental concepts of HTML, learned how to organize website content, and became more comfortable working with the command line, Git, and GitHub.

This project represents my first practical step towards becoming a web developer.

🎯 Skills and Concepts Learned

During this project and the preceding Foundations lessons, I developed and practiced the following skills:

1. HTML Fundamentals
Understanding the structure of an HTML document.
Working with HTML boilerplate.
Using <!DOCTYPE html>, <html>, <head>, and <body>.
Understanding the difference between elements and tags.
Using headings (<h1>–<h6>) to organize content.
Creating paragraphs with <p>.
Using bold and italic text with <strong> and <em>.
Understanding semantic HTML and the importance of meaningful markup.
2. Links and Images
Creating hyperlinks using the <a> element.
Understanding relative and absolute paths.
Linking between different pages within a website.
Displaying images using the <img> element.
Working with image paths and file extensions.
Using the alt attribute to improve accessibility.
3. Lists and Content Organization
Creating unordered lists using <ul>.
Creating ordered lists using <ol>.
Adding list items with <li>.
Structuring information in a readable and organized way.
4. Working with Files and Directories
Understanding website project structures.
Organizing HTML files and image assets into directories.
Using relative paths to reference files.
Understanding the importance of a clean and consistent folder structure.
5. Command Line Basics
Navigating directories through the terminal.
Understanding basic shell commands.
Creating and managing files and directories.
Using the terminal as part of the development workflow.
6. Git and GitHub
Understanding version control and why it matters.
Initializing a Git repository.
Staging changes using git add.
Creating commits using git commit.
Writing meaningful commit messages.
Connecting a local repository to GitHub.
Pushing project files to a remote repository.
Understanding the importance of regular commits and project history.
7. Developer Workflow
Working with Visual Studio Code as a code editor.
Using the browser to preview and test HTML pages.
Reading and understanding basic HTML errors.
Developing the habit of saving, testing, and reviewing code.
Using documentation and learning resources to solve problems independently.
🛠️ Technologies and Tools
HTML5 – Website structure and content.
Visual Studio Code – Code editor.
Git – Version control.
GitHub – Remote repository hosting.
Command Line / Terminal – File management and development workflow.
Web Browser – Testing and previewing the website.

💡 Challenges and Takeaways

One of the most important lessons from this project was understanding that building a website is not just about writing HTML tags. It is also about structuring information, organizing files, understanding paths, and maintaining a consistent development workflow.

Some of my key takeaways:

Writing clean and readable HTML makes future development easier.
Proper file organization prevents unnecessary confusion.
Relative paths are essential when connecting different pages and resources.
Git provides a reliable way to track progress and manage changes.
Small, consistent steps are more effective than trying to learn everything at once.
Understanding the fundamentals is more important than rushing into advanced technologies.
